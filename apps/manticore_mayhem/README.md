# Manticore Mayhem — frontend

8x8 cluster-drop slot with doubling multiplier tiles. Forked from `apps/angry_mantis` on
2026-09-22 (milestone 1). Svelte 5 runes + Pixi 8, shared packages from `web-sdk/packages`.

- Spec: `~/Projects/manticore/docs/manticore-spec.md`
- Math package: `math-sdk/games/manticore_mayhem/` — `EVENT_SCHEMA.md` is the contract
- House rules: `.claude/skills/angry-mantis-house-rules/SKILL.md` (they all carry over)

## Run it

```sh
# mock RGS for this game (its own book cache under tools/.rgs-cache/manticore_mayhem)
math-sdk/env/bin/python tools/mock_rgs.py --game manticore_mayhem --port 8444

pnpm dev      # http://localhost:3008
```

Then open `http://localhost:3008/?rgs_url=localhost:8444&sessionID=<anything>&lang=en`.
Chrome needs a one-time click-through at `https://localhost:8444/fair/state` (self-signed cert).
Force an outcome: `curl -sk "https://localhost:8444/debug/force?criteria=epicgame&session=<sid>"`
(or `criteria=book:<id>` for one exact book).

Angry Mantis keeps port 3007 / 8443; the two games run side by side.

## What milestone 1 is

Board, HUD and event playback. No intros, no outros, no cinematics, no manticore character, no
production art: every tile is a flat coloured plate with its code id and tier word, generated by
`tools/make_placeholders.py`. Feature start and end are one plain mode plaque.

The HUD is Angry Mantis's, verbatim, re-skinned only where the Persian theme needs a colour. The
feature menu's name is a placeholder: `FEATURE_MENU_NAME` in `src/game/constants.ts` (BAZAAR), one
constant so Corey's final pick is a single edit.

## Layout

- `src/game/` — constants, layoutSpec, assets, sound, bookEventHandlerMap, deviceTier, assetStamp
- `src/game/stateGame.svelte.ts` — the board engine: 64 cells, one rAF loop, every move book-driven
- `src/components/` — the Pixi scene
- `src/ui/` — the HTML chrome (Angry Mantis's, verbatim)

## Rebuilding the placeholder art

```sh
math-sdk/env/bin/python tools/make_placeholders.py
```

Writes the symbol atlas (plus its half-resolution phone twin), the per-symbol tiles the Game Info
paytable uses, the board backdrop, the logo, the tagline strip and the three primer cards.
`scripts/stamp-assets.mjs` runs on every `pnpm dev` / `pnpm build` and re-stamps them.

## Gates

```sh
pnpm dlx svelte-check --threshold error     # 7 errors, all in infrastructure files (baseline)
```

The milestone-1 Playwright probe lives in the session scratchpad (`probe.js`): 30 base spins plus
one forced round of every mode, checking that the frontend's final win equals the book's
`payoutMultiplier` x the bet, and screenshotting each layout mid-tumble and mid-feature.
